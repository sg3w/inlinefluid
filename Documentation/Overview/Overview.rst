Overview
========

Inlinefluid is designed as an inline Fluid rendering engine for TYPO3 content elements.

It allows Fluid templates to be written directly in the TYPO3 backend and rendered
at runtime without the need to create a dedicated Extbase plugin for each use case.

The main goal of Inlinefluid is to provide maximum flexibility for developers and
integrators while keeping the setup lightweight and fast.

Typical use cases include:

- Ad-hoc UI components
- Rapid prototyping
- Small widgets
- Demo or proof-of-concept integrations
