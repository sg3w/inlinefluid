Inlinefluid TYPO3 Extension
===========================

Inlinefluid is a TYPO3 extension that allows editors and integrators to enter and render
Fluid templates directly in the TYPO3 backend using a dedicated CType.

The extension supports cached and non-cached rendering, variable providers,
static and dynamic data sources, FAL-based media handling and HTML injection
before and after rendering.
